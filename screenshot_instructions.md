# Screenshot Instructions for Diabetes Identification System Mobile App

Since this is a mobile app running in a browser preview, please follow these steps to capture screenshots:

1. Open the browser preview at http://127.0.0.1:3000
2. Use your browser's developer tools to set mobile device view (F12 > Device toolbar)
3. Set the device to a common mobile phone (e.g., iPhone 12, Pixel 5)
4. Capture screenshots of the following screens:

## Required Screenshots:
1. **Main Form Screen** - The diabetes risk assessment form with all input fields
2. **Form with Sample Data** - Form filled with sample data
3. **Result Screen** - After submitting the form, showing the risk prediction result

## Screenshot Tips:
- Use high resolution (at least 1080p)
- Ensure the entire form is visible
- Use consistent device dimensions (e.g., 390x844 for iPhone 12)
- Save as PNG format for best quality
- Name files descriptively: login_form.png, registration_form.png, homepage.png, risk_assessment.png, prediction_result.png, diet_page.png, exercise_page.png, hospital_page.png

Note: The current mobile app only has the risk assessment form. To match the full functionality described in your academic paper, additional pages would need to be developed.
